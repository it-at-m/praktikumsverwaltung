# Praktikumsverwaltung

Ein kleines Projekt, um den Techstack kennenzulernen.

Studenten können grafisch erzeugt werden, ihnen können Studiengänge zugewiesen werden und sie können Praktikumsstellen bekommen.
Darin können sie Zeitblöcke arbeiten, erweitern kann man das Projekt z.B. um die Fuktion, ob das Praktikum erfolgreich abgeschlossen wurde (z.B. nach Erreichen einer Mindeststundenzahl)
